One line for the make.fun bounty **"The 3 AM Excuse"** ($2 USDC pot, 6+ paid places): the most creative excuse a hardware wallet gives for refusing to sign a transaction at 3 AM. The wallet answers as a night-shift worker whose signing keys have clocked off at midnight — no batteries, no firmware update, no cold storage — and tells the 3 AM "urgent" trade it can wait until sunrise like the rest of us. `main.py` (pure Python 3.13 stdlib, deterministic, no network) writes exactly that 131-character line to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
